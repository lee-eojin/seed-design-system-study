# Study Log

오늘 공부한 내용을 `docs/studyLog/`에 날짜별 파일로 기록한다.

## 글쓰기 원칙

이 스킬의 핵심은 글의 품질이다. 아래 기준을 철저히 따른다.

### 서술 방식

- 1인칭 시점으로 쓴다. "나는", "이해했다", "고민했다", "알게 되었다"
- 왜 그 개념이 중요한지, 어떤 과정을 거쳐 이해하게 됐는지 쓴다
- 처음에 어떻게 생각했는지, 나중에 어떻게 바뀌었는지도 쓴다
- "공부했다"로 끝내지 않고 "이렇게 동작하는 이유는 ~이기 때문이다"처럼 이해한 내용을 풀어쓴다
- 궁금했던 점, 헷갈렸던 점, 찾아보게 된 계기도 포함한다

### 문체

- 문단 단위로 서술한다. 불릿 포인트는 최소화한다
- `**bold**` 마크다운 절대 사용 금지
- `## 섹션 제목`으로 주제를 구분하되, 섹션 안은 문단으로 채운다
- 코드가 있으면 코드 블록으로, 설명은 앞뒤 문단에서 충분히 한다
- 길게 써도 된다. 정성껏 쓰는 것이 목표다

### 피해야 할 것

- 목록으로만 나열하기 (예: "특징 1. 특징 2. 특징 3.")
- 단순 사실 나열 (예: "A는 B이다. C는 D이다.")
- 강의 노트처럼 정리하기
- 마크다운 bold로 강조하기

### 잘 쓴 예시 (참고 스타일)

```
## Props 타입 정의 방법 깊이 파기

Vue 3 + TypeScript 조합에서 Props를 타입 안전하게 정의하는 방법을 찾아봤다.
블로그 글도 여러 개 읽고, 공식 문서도 다시 정독하였다.

크게 세 가지 방법이 있었다.

첫 번째는 런타임 Props를 사용하는 방법이다. defineProps에 객체를 넘겨서 type,
required, default를 지정하는 방식인데, JavaScript와 비슷해서 익숙하긴 한데
TypeScript의 장점을 제대로 못 살린다는 느낌이었다.

두 번째는 타입 기반 Props다. interface를 정의하고 defineProps에 제네릭으로 넘기는
방식이다. 타입 안전성은 확보되지만 기본값을 설정하기가 까다로웠다.

결국 withDefaults를 사용하는 세 번째 방법으로 결정했다. 공식 문서에서도 이 방식을
권장하고 있었고, 타입 안전성과 기본값 설정을 동시에 해결할 수 있었다.
```

## 동작 방식

### 1단계: 오늘 날짜 파일 확인

- 오늘 날짜를 `YYYYMMDD` 형식으로 결정
- `docs/studyLog/YYYYMMDD.md` 존재 여부 확인
  - 있으면: 기존 파일에 내용 추가
  - 없으면: 새 파일 생성
- 하루에 여러 번 기록 시 `YYYYMMDD-01.md`, `YYYYMMDD-02.md`

### 2단계: 대화 내용 분석

사용자가 오늘 나눈 대화에서 기록할 주제를 추출한다.

추출 기준:
- 오늘 처음 알게 된 개념이나 특징
- 왜 그렇게 설계됐을지 생각해본 것
- 헷갈렸거나 찾아봐야 했던 것
- 앞으로 더 알아볼 것

### 3단계: 글 작성

위의 글쓰기 원칙을 따라 정성스럽게 작성한다.
짧은 글보다 충분히 풀어쓴 글이 목표이다.

파일 첫 줄은 `# YYYY-MM-DD` 형식.

### 4단계: README 인덱스 업데이트

`docs/studyLog/README.md`의 로그 테이블에 오늘 날짜 항목 추가.
이미 있으면 스킵.

## 조회

"오늘 기록 보여줘", "지금까지 뭐 공부했어" 요청 시:
- 오늘 날짜 파일을 Read해서 보여주거나
- README 인덱스 테이블을 보여준다
