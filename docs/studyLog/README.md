# SEED Design Study Log

당근 디자인 시스템 SEED Design을 공부하면서 매일 기록하는 로그.

## 목표

좋은 디자인 시스템은 어떤 고민으로 설계되는지 이해한다. 만드는 사람의 시각으로 보면서, 왜 디자인 시스템이 중요한지 스스로 납득한다.

## 측정 기준

- [ ] 컴포넌트 2개 이상 분석한 글 작성 완료
- [ ] 매주 종합 글 1편씩, 총 2편 작성 완료
- [ ] 분석한 내용을 바탕으로 컴포넌트 하나 이상을 직접 따라 만들어보기
- [ ] 실제 당근 앱에서 찾은 UX 패턴 5개 이상 정리 (왜 그렇게 구현했을지 예상 포함)
